# Android Troubleshooting

This directory contains diagnostics for the supported Kaiteyo product target: ARM64-v8a Android devices on Android 12 or newer.

| Document | Scope |
|---|---|
| [`Android.md`](Android.md) | Android SDK/JDK setup, compile/test/APK commands, logs, device validation, and cleanup checks |

When recording an issue, include the symptom, reproducible command or UI path, root cause, minimal fix, and exact verification evidence. Do not add diagnostics for desktop, iOS, web, or removed product targets.
